# Collaboration pitch — draft

## 15 seconds

An agent saying ‘done’ is not evidence. I build Python AI automation, execution verification and regression tests. I’m looking for one team with two or three anonymized failure cases for a small paid, read-only pilot.

## 30 seconds

An agent saying ‘done’ is not evidence. Mermail Send Verifier compares a completion claim with the selected email record and shows what remains unknown. A separate Avalanche experiment checks execution receipts while keeping payment relationships unverified. I work on Python AI automation, execution verification and regression testing. My ask is one team, one real workflow, and two or three anonymized failure cases for a small paid, read-only pilot.

## Small pilot ask

Could one team share 2–3 anonymized failure cases from one real automation workflow, including the completion claim, the expected outcome and a minimal redacted evidence sample?

Proposed scope: agree on observable acceptance, reproduce each case locally, produce a claim-versus-evidence report, and retain deterministic regression tests. The pilot is read-only: no production writes, customer mail access, credentials in shared material, wallet actions or payment execution. Start with local anonymized samples; any later connection needs a separately agreed scope.

Review the report's usefulness and the regressions against the agreed cases before discussing further work. Fee, timeline and access are to be agreed with the team. This draft makes no promise of security, financial results or universal detection.
